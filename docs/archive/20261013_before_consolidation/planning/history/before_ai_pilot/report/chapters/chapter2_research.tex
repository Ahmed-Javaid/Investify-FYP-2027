\chapter{Research and Existing Solutions}
\section{Research Method / Approach}
This preliminary review uses primary research abstracts, the actual sentiment checkpoint's model card, official exchange/API documentation, and the preserved project artifacts. The comparison is focused on sentiment inputs, time alignment, attribution and explanation consistency. It is not a completed systematic literature review or evidence that no other product provides similar features.
\section{Existing Solutions / Products}
Araci's FinBERT work investigates domain-adapted language models for financial sentiment \cite{finbert_paper}. The implemented checkpoint, \texttt{ProsusAI/finbert}, outputs positive/neutral/negative sentiment scores and is documented separately by its provider \cite{finbert_card}. Investify transforms these outputs into historical news features; their availability alone does not establish return predictability or social-domain transfer.

FNSPID combines financial news with stock-price data for forecasting research \cite{fnspid_paper}. The project's preserved subset probe concerns the actual selected files/tickers and timestamp precision. It must not be generalised into a claim that every record in the published dataset has the same limitation. Supplemental Alpaca/Benzinga results remain a separate experiment.

Tree-based SHAP work provides consistent local feature attributions \cite{treeshap_paper}. Investify uses stored predicted-class attributions to explain raw model scores. The verifier and educational display are downstream additions, not inventions of TreeSHAP or guarantees of economic causation.

Parcalabescu and Frank distinguish output-level self-consistency tests from stronger claims about a language model's internal explanation faithfulness \cite{faithfulness_paper}. This motivates a precise boundary: Investify checks supported statements against an external decision record and a maintained glossary. It does not prove all natural-language meaning or the LLM's internal reasoning faithful.

\section{Limitations and Gaps}
The engineering gap demonstrated locally is that a correct JSON payload could hide an incorrect displayed explanation. Concrete regressions establish this defect and its correction. A broader research novelty claim requires comparison with the closest record-grounded generation and checking approaches. Adding an LLM or SHAP alone is insufficient. Human understanding, unrestricted language verification, social transfer and useful stock prediction remain unestablished.
\section{Proposed Solution}
Investify combines temporal evaluation controls with explanation claims traceable to recorded inputs/attributions. Visible text and JSON are checked independently, known contradictions fail, and unsupported/failed generations select a verified deterministic explanation. The local pilot includes exact maintained definitions and compares numeric template, definition-enhanced template and real generations on a frozen chronological selection. No quality score is reported if the provider returns no completion.
\section{Complex Computing Problem}
The problem combines asynchronous text and trading calendars, overlapping prediction horizons, fold-local processing, model calibration/attribution, and generation whose displayed claims must remain consistent with external numerical facts. The interfaces have competing constraints: understandable explanations need adequate coverage, while checking must avoid accepting unsupported claims or rejecting all useful content. Institutional mapping to the required complex-computing-problem criteria still requires supervisor/team review.
\section{Technical Challenges}
Publication precision, session/half-day boundaries, missing data, calibration collapse and raw-score interpretation complicate the baseline. Raw/store inputs and the scientific environment remain absent; the separate viewer environment is restored. Fresh default LM Studio/Ollama probes return no model identifier. The inspected model directory names an old C: target, while E: contains application/backends and a bundled embedding model but no discovered generative weights. Global configuration is unchanged; these observations do not establish all failure causes or generation/deployment completion.

The social-model study distinguishes post sentiment from return prediction. CryptoBERT's provider documents crypto-social training, bearish/neutral/bullish class indices and a 128-token training length \cite{cryptobert_card}; a generic Twitter alternative documents different sentiment names and mention/URL preprocessing \cite{twitter_sentiment_card}. Equity-domain suitability therefore needs the actual labelled study, not a model-name preference. The local-only runner records explicit mappings, token/truncation information and failed outcomes; missing/randomly initialized classifier heads are refused. Tests use a fixture backend, and no actual classifier inference is reported.

FinLin provides a multi-source entity-level research design, with individual annotations in its described schema \cite{finlin_paper,finlin_repository}. The inspected repository contains descriptions/figures rather than the corpus; no access request has been sent. The comprehensive StockTwits project describes public-access joined message/metadata tables and user sentiment tags \cite{stocktwits_records}. Such tags do not provide new independent human labels or a neutral class. Corpus access, permitted use, published-score handling and pretraining overlap require explicit review. A chronological benchmark split alone does not prove absence from model pretraining.
\section{Research Findings and Design Decisions}
Stocks represent ownership interests, and price movement can reflect company-specific or wider market events \cite{sec_stocks}. The prototype's technical/news features do not provide a full valuation or represent every fundamental/macroeconomic driver. A worked explanation must distinguish what its actual inputs measure from unsupported claims about why a market price changed. Corporate-action adjustment, broader drivers and changing regimes still require dedicated review.

NVIDIA's official 2021 FAQ documents a four-for-one split and trading on the new basis from 20 July \cite{nvda_split_2021}. As a worked arithmetic illustration, one share at 100 units becoming four shares at 25 units preserves 100 units of value; treating the per-share change as a 75\% investment loss would omit the share-count change. These numbers illustrate arithmetic and are not observed NVDA prices. Yahoo describes adjusted close as accounting for splits and distributions \cite{yahoo_adjusted_close}. The current ingest disables yfinance's client adjustment and omits action columns \cite{yfinance_download}; that setting alone does not verify provider Close/Volume are as-traded. The raw snapshot, action history and volume basis require audit before any adjustment or performance claim. This issue has not been established as a cause of constant-Buy output.

Official exchange hours include regular and early-close schedules \cite{nyse_calendar}; alignment must therefore use an explicit decision-time contract and exchange calendar rather than calendar-date equality. The calendar cutoff/proposal reconciliation remains open. Model-card sentiment outputs motivate a news-specific pipeline and separate equity-social study. Attribution theory motivates additivity checks and clear raw-score units. Explanation-consistency literature motivates bounded, explicit claims rather than a claim of universal semantic faithfulness. Local structured-output documentation supports JSON-schema requests, but schema conformance does not replace factual checks \cite{lmstudio_structured}.
