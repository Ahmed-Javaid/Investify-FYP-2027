# Equity-social corpus access review

11 October 2026. This review identifies sources and access gaps; **no real corpus has been acquired, annotated or evaluated**. Published labels/tags are not relabelled as new independent team annotations.

| Source | Relevant evidence | Current access/benchmark implication |
| --- | --- | --- |
| [FinLin author repository](https://github.com/TDaudert/FinLin) and [original paper](https://arxiv.org/abs/2003.04073) | Entity-level financial sentiment across several source types; schema includes time, target, individual annotations and spans. The author states CC BY-NC-SA 4.0 for noncommercial use. | The inspected repository contains a README and two figures, not the corpus. Its obtaining-data instructions direct readers to the author. No message has been sent. Filter StockTwits and eligible equities if access is obtained; do not treat news/report rows as social posts. |
| [SemEval-2017 Task 5](https://alt.qcri.org/semeval2017/task5/index.php?id=data-and-tools) and [release agreement](https://alt.qcri.org/semeval2017/task5/data/uploads/gsdatareleaseagreement-semeval-task5.pdf) | Financial microblogs and news are separate subtasks. The release describes annotation licensing and source-specific terms. | Access/terms and required publication/provenance fields need confirmation. A fine-grained published score cannot be silently converted into the project's independently annotated three-class gold labels. No agreement is signed or submitted. |
| [StockTwits comprehensive-records project](https://github.com/Jaxingjili/StockTwits-from-2008-to-2022) and [access guide](https://github.com/Jaxingjili/StockTwits-from-2008-to-2022/blob/main/dataset_access.md) | Public S3 access is documented. Message text and timestamp/ticker metadata are separate tables joined by message ID; bullish/bearish tags are user-supplied. | A bounded sample and explicit permitted-use conditions need review; no full-bucket sync/download has been performed. User tags do not replace two independent human labels or provide a neutral class. The inspected repository states access instructions but no explicit corpus redistribution license was located. |

An acquired candidate pool must retain original IDs/URLs/timestamps/text, source/access conditions, declared equities/window/sampling, and duplicates/exclusions. Prepare independent blind annotation assignments before modelling. Keep any published source scores/tags separate from new initial labels to avoid treating them as independent evidence.

Pretraining overlap is a separate limitation from a chronological study split. The inspected social-model cards describe historical training corpora; a development/held-out division of old posts does not prove those posts were absent from model training. Prefer a documented later/unseen cohort when available, inspect source overlap, and report uncertainty instead of making an uncontaminated-test claim. Genuine human annotation, exact local classifier snapshots and adequacy criteria remain required.
