\addcontentsline{toc}{chapter}{Abstract}
Investify is an educational equity decision-support project addressing time-sensitive input alignment and understandable explanations consistent with recorded evidence. The historical baseline combines technical indicators and financial-news sentiment and stores predictions with attributions. The increment adds complete evidence descriptions, independent prose/JSON checks, strict supported-claim handling and verified fallback. Both local interfaces execute these paths. A local LLM adapter and frozen chronological evaluation are implemented with a complete-guided deterministic comparator. An explicit prototype capacity/tolerance profile now conditions a separate retrospective linear blend; saved classifier outputs remain unchanged. The selected suite has 136 passes and no skips, including actual Streamlit tests. All 372 saved records/guided explanations, 62 live HTTP checks and 228 comparator arithmetic probes validate. Real explainer generations and human validation remain unavailable. The actual AI reference pilot contains 200 real MSFT tweets: 117 usable labels (31 positive, 67 neutral, 19 negative) and 83 explicit exclusions. Its frozen split is 93 development/24 held out, with only two negative held-out references. One session pass is recorded with full prompt/input/raw-output/timing and declared model-identity provenance; agreement/kappa are null and independent human validation is absent. Candidate inference remains blocked with null metrics. Both saved classifier folds predict Buy throughout; no predictive-skill or investor-suitability result is claimed. Remaining work includes scientific data/environment restoration, real generation evaluation, AI-reference social comparison, approved risk semantics, broader evaluation and deployment. This source draft awaits compilation, institutional details and team review.
