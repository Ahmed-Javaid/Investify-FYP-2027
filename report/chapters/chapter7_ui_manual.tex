\section{Recovery and Boundaries}
Missing or invalid recorded data yields an explicit error rather than a different synthetic decision. A development-block session refuses the profile comparator. Incomplete questions produce no assumed profile. Invalid study evidence withholds comparison scores. A failed checker claims no verified output. The optional local-model control makes a request only when explicitly invoked; an unconfigured model returns a labelled deterministic guide. Broker orders, accounts, profile persistence and trained-student inference are absent.
