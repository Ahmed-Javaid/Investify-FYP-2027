\section{Local Installation}
Install Git and Python 3.11, clone the repository, create a virtual environment and install \nolinkurl{code/requirements-demo-runtime.txt}. Restore reviewed checkout bytes with \nolinkurl{tools/restore_ci_checkout.py}. Start the app from the repository root:
\begin{quote}\small\begin{verbatim}
python -m streamlit run code/app/streamlit_app.py
  --server.address=127.0.0.1 --server.port=8507
\end{verbatim}\end{quote}
The command should be entered on one line. Open \url{http://127.0.0.1:8507} and keep the terminal open. No GPU, model download or API key is needed for recorded viewing. The prepared project laptop can use \nolinkurl{tools/start_guided_demo.ps1}; a different machine should follow the portable setup. An occupied port or missing runtime produces an error; use an available port/environment rather than stopping an unrelated process.

\section{Failure Handling}
Missing records, invalid profiles, inconsistent study identities and checker errors withhold substitute outputs. A failed fallback produces an error. The optional generator is called only by explicit action, and its absence is labelled. Brokerage accounts, orders and trained-student serving remain outside this prototype.
