\chapter{Proposal Feedback and Iteration Plan}
\section{Proposal Feedback}
The project was approved with minor modifications. The panel requested clearer contributions and model choices, an explanation of the LLM's user benefit, technical/sentiment evidence, explicit metrics, an improved PoC, transparency and deeper market understanding. Appendix~\ref{app:actions} links each action to the current response and remaining evaluation.
\section{Iteration Strategy}
Each increment delivers runnable behavior, source-linked tests and retained evidence. New experiments use new identities so earlier inputs and findings remain reproducible. The prototype distinguishes implemented controls from unproven predictive or participant outcomes.

\section{Deviations and Recovery}
FNSPID's timestamp precision and ticker gaps prompted a bounded NVDA study and a new Alpaca/Benzinga snapshot. FinBERT remains the headline model; Cardiff is an evaluated social alternative. The isotonic collapse prompted a separately identified multiclass revision and abstention guard. The original sentiment-weight profile was replaced in the main interface by complete tolerance scoring and a direction-preserving confidence policy. Earlier records and labels remain unchanged.
